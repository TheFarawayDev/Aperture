System Operations & Search Guide

Directory Syntax & Hotkeys

Standard Navigation

The directory uses intelligent fuzzy-matching. You can type partial names, rooms, or teacher names directly into the search bar. Use the dropdown menus to broadly filter by grade, teacher, or specific periods without needing syntax.

Advanced Search Operators

Combine precise filters using comma-separated clauses and colon operators key: value.

teach: [name] Finds students with a specific teacher at any point.
activeper: [1-7] Scopes room/teacher searches strictly to a specific period.
room: [number] Finds students located in a specific room number.
lunch: [A/B/C] Finds students assigned to a specific lunch block.
Example Query: marshall, activeper: 5, teach: phiri

Locates "Marshall" specifically when in "Phiri's" class during "Period 5".
