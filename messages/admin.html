Reset the database?

This permanently deletes, for every user: nicknames, accounts, profile pictures & keys, every DM and group chat, blocks, bans, and open reports.

It does not delete admin accounts or the shared chat encryption key, so admins stay signed in. Everyone else is signed out and has to create a new account.

This cannot be undone. Only do this right before shipping an update that needs a clean start.
